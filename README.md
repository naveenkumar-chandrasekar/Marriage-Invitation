# Marriage Invitation

A Next.js site for our wedding invitation — bride & groom details, events, and venues.

Currently placeholder content in [app/page.tsx](app/page.tsx); real details go in next.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Deploy

Push to a Git repo and import it on [Vercel](https://vercel.com/new) — no config needed, it auto-detects Next.js.
